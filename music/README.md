# Hudba
`python3 music/compose.py` — vlastní procedurálně složené skladby (bez samplů, bez cizích licencí):
- `noc_na_klisi.mp3` — temný boom-bap 88 BPM (Am–F–G–Em7, 808, piano, vinyl)
- `chemicka_174.mp3` — liquid/neuro DnB 174 BPM (Dm–Bb–F–C, reese bas, arp)

V rádiu jako stanice **NOC NA KLÍŠI** a **CHEMIČKA 174**. Další skladby z Suno/Udio/Stable Audio stačí dát do `public/music/` a přidat do `STY` v `index.html` s `file:`.
